# Porträt-Klassifikation

Interaktives Lernprogramm für den Kunst-Leistungskurs. Einzeldatei, läuft offline im Browser, auch auf iPad und iPhone.

- **Ausrichtung zum Betrachter:** Drehung des Kopfes (frontal bis verlorenes Profil) und Bildausschnitt (Ganzfigur bis Kopfbild) lassen sich auf demselben Bild kombinieren.
- **Perspektive:** Kamerahöhe von Untersicht über Augenhöhe bis Vogelperspektive, als Ganzfigur und Schulterstück. Keine Regler.

Die Begriffe und Wirkungen der Perspektive sind ergänzt und stammen nicht aus der Textvorlage. Die Beispielwerke stammen aus der Textvorlage.

Die Datei `index.html` ist direkt über GitHub Pages veröffentlichbar.
