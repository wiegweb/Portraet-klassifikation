# Porträt-Klassifikation

Interaktives Lernprogramm für den Kunst-Leistungskurs. Einzeldatei, läuft offline im Browser, auch auf iPad und iPhone.

- **Ausrichtung zum Betrachter:** Kamerahöhe von Untersicht über Augenhöhe bis Vogelperspektive. Fachbegriff, Merkmal und Wirkung erscheinen zum Bild.
- **Bildausschnitt:** Ausschnitt von der Ganzfigur bis zum Kopfbild, dazu die Ausrichtung zum Betrachter. Der Rahmen bleibt gleich.

Die Begriffe und Wirkungen der Ausrichtung sind ergänzt und stammen nicht aus der Textvorlage. Die Beispielwerke stammen aus der Textvorlage.

Die Datei `index.html` ist direkt über GitHub Pages veröffentlichbar.
